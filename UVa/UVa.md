

### 🔢 數學與數論 (Math, Number Theory & Combinatorics)

這些題目主要測驗整數性質（質數、公因數/公倍數、同餘）、大數運算、排列組合、機率或特定數學數列（如費氏數列、卡特蘭數、約瑟夫問題）。

* All You Need Is Love (進制轉換、最大公因數 GCD)
* Bangla Numbers (大數與進制表示)
* Bee Maja (蜂巢座標與數學規律)
* Big Mod (模運算、快速冪)
* Count the Trees (卡特蘭數、排列組合)
* Digit Primes (質數篩法、區間質數)
* Euclid Problem (擴展歐幾里得演算法)
* Generate random numbers (循環節、模擬)
* I Love Big Numbers ! (大數階乘與數字和)
* Irreducible Basic Fractions (歐拉函數)
* Joseph's Cousin (約瑟夫問題、質數)
* Last Digit (同餘與快速冪)
* Light, more light (完全平方數因數性質)
* Marbles (擴展歐幾里得、線性不定方程)
* Opening Doors (完全平方數性質)
* Perfection (因數總和)
* Power Crisis (約瑟夫問題)
* Prime Distance (區間質數篩法)
* Quirksome Squares (數學規律、暴力窮舉)
* Recursion and Mod (遞迴與模運算)
* Safe Salutations (卡特蘭數)
* Show the Sequence (數列推導與解析)
* Smith Numbers (質因數分解、數字和)
* Square root (大數開根號)
* Sum of Consecutive Prime Numbers (質數篩法、滑動窗口/前綴和)
* The Hotel with Infinite Rooms (等差數列與前綴和)
* The Priest Mathematician (河內塔變體與規律)
* The Trip (平均數與誤差計算)
* Urn-ball Probabilities! (機率與期望值)

### 🧩 動態規劃 (Dynamic Programming, DP)

測驗狀態轉移、背包問題、最長遞增/共通子序列（LIS/LCS）、區間 DP 等。

* Bachet's Game (賽局 DP)
* Brick Wall Patterns (費波那契數列 DP)
* Climbing Stairs (爬樓梯問題、排列組合 DP)
* Cutting Sticks (區間 DP)
* Divisibility (狀態 DP / 同餘 DP)
* Dollars (零錢問題 / 完全背包)
* Homer Simpson (完全背包 / 貪婪)
* Is Bigger Smarter? (最長遞增子序列 LIS 變體)
* Largest Square (最大正方形 / 2D DP)
* Longest Common Subsequence (最長公共子序列 LCS)
* Longest Increasing Subsequence (最長遞增子序列 LIS)
* Longest monotonically increasing subsequence (LIS)
* Luggage (子集和問題 / 0-1背包)
* Making Change (找零問題 / 有限背包)
* Maximum Product (最大連續乘積 DP / 1D DP)
* Minimum Path Sum (棋盤路徑 DP)
* Set partition (集合劃分 / 狀態壓縮 DP)
* Simple Minded Hashing (三維 DP)
* Take the Land (最大二維子矩陣 / 2D Kadane's)
* The jackpot (最大連續子陣列和 / Kadane's Algorithm)
* Tight words (機率 DP / 狀態轉移)
* Tug of War (子集和問題 / 0-1背包變體)
* Wavio Sequence (雙向 LIS)

### 🕸️ 圖論與樹 (Graph Theory & Trees)

包含廣度/深度優先搜尋（BFS/DFS）、最短路徑、最小生成樹、二分圖匹配或網路流。

* Dungeon Master (三維迷宮 BFS 最短路)
* Eternal Truths (狀態轉移 BFS)
* Gopher II (二分圖最大匹配 / 最大流)
* Longest Paths (有向無環圖 DAG 最長路)
* Network Connections (並查集 Disjoint Set)
* Oil Deposits (連通塊搜尋 DFS/BFS)
* Rank the Languages (二維網格連通塊 DFS/BFS)
* Roads in the North (樹的直徑)
* Snow Clearing (尤拉迴路 Eulerian Tour)
* Solving Maze Problems (迷宮 DFS/BFS)
* The Tourist Guide (最短路徑變體 / Minimax / Floyd-Warshall)
* Matrix Decompressing (網路流 Max Flow - 視題意也常被歸類在圖論)

### 🔠 字串處理 (String Processing)

包含字串比對、KMP 演算法、迴文判斷、字典序或編碼壓縮。

* Automated Judge Script (字串比對與過濾)
* Common Permutation (字串字元頻率與排序)
* COUNTING CHAOS (字串翻轉與迴文)
* Extend to Palindromes (字串匹配 / KMP / 迴文)
* Glass Beads (最小字串表示法 / 字串輪轉)
* Lexicographic Order (字典序排列)
* Power Strings (字串週期 / KMP)
* Uncompress (字串壓縮與解析)
* Zipf's Law (字串解析與詞頻統計)

### 📦 資料結構 (Data Structures)

著重於 Stack、Queue、Tree、Trie、Hash Map 或優先佇列的應用。

* Binary tree traversals (二元樹遍歷：前序/中序/後序互推)
* Conformity (Hash Map / 字典統計)
* Disk Tree (Trie 字典樹與目錄格式化列印)
* Hay Points (Hash Map 查表)
* Parser and evaluator (Stack / 表達式解析)
* Prefix expression evaluation (Stack / 前綴表達式計算)
* The N-th Element (特殊資料結構查詢)

### 🏃 模擬與實作 (Simulation & Ad-Hoc)

按照題目給定的規則進行程式流程模擬，無特定複雜演算法，但考驗實作細心度。

* A mid-summer night's dream (中位數尋找 / 排序邏輯)
* Cola (生活邏輯模擬 / 簡單數學)
* Contest Scoreboard (排序、規則模擬)
* Die Game (骰子翻轉立體模擬)
* Mine Sweeper (Minesweeper) (踩地雷二維陣列邏輯)
* Robot Instructions (指令狀態模擬)
* Zeros and Ones (陣列/字串簡單掃描)

### 🎯 貪婪策略與搜尋 (Greedy, Search & Backtracking)

包含貪婪法則（局部最優解）、二分搜尋（Bisection）、回溯法（Backtracking）。

* Camel trading (貪婪與表達式極值)
* Children's Game (貪婪排序 / 字串組合)
* Fill the Containers (二分搜尋法對答案進行 Bisection)
* Minimal coverage (區間貪婪覆蓋)
* Missing Numbers (陣列搜尋 / 排序)
* Necklace (貪婪與公式最佳化)
* Sudoku (As Good As Lee Hsien Loong) (回溯法 Backtracking)
* Sumsets (折半枚舉 / Meet in the middle)
* The Grand Dinner (貪婪法則 / 或可用最大流解)

### 📐 幾何 (Computational Geometry)

點、線、圓的方程式、座標轉換、面積計算或圖形相交問題。

* Antimatter Ray Clearcutting (幾何射線與位元壓縮搜尋)
* Center of Masses (質心計算 / 多邊形幾何)
* Curling up the cube (展開圖還原 / 3D 幾何與模擬)
* How Big Is It? (圓形相切排列 / 幾何與回溯)
* Is This Integration ? (圓形交集面積計算)
* Line Overlap Problem (線段重疊計算)
* Packing polygons (多邊形與圓形包覆計算)
* Unique lines (座標幾何 / 找出不重複直線)
